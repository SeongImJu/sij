# ⚔️ 주사위 HP 배틀 — 공격/회피

주사위를 굴려 상대의 HP를 0으로 만드는 턴제 대결 웹 게임입니다.

## ▶️ 바로 플레이하기

**[👉 게임 실행하기](https://seongimju.github.io/sij/)**

> GitHub Pages가 아직 켜져 있지 않다면 위 링크가 열리지 않을 수 있습니다. 저장소 **Settings → Pages**에서 `main` 브랜치를 배포해 주세요.

## 🎮 게임 방법

1. 화면 왼쪽 **주사위 1 (나)**의 행동을 **공격** 또는 **회피** 중에서 선택합니다.
2. 오른쪽 **주사위 2 (AI)**는 매 라운드 자동(무작위)으로 공격/회피를 선택합니다.
3. **⚡ 굴리기** 버튼을 누르면 두 주사위가 동시에 굴러갑니다.
4. 규칙에 따라 피해가 계산되고 HP 바가 줄어듭니다.
5. 어느 한쪽의 HP가 0이 되면 승패가 결정됩니다.
6. **기록 및 초기화** 버튼으로 HP와 라운드 기록을 리셋하고 다시 시작할 수 있습니다.

## 📜 전투 규칙

| 상황 | 결과 |
|---|---|
| **공격 vs 공격** | 낮은 눈을 굴린 쪽이 높은 눈을 굴린 쪽에게 공격당함. 피해량 = 두 눈의 차이 |
| **공격 vs 회피** | 공격 눈이 회피 눈보다 **높으면** 관통 피해(차이만큼), 같거나 **낮으면** 회피 성공(무피해) |
| **회피 vs 회피** | 서로 피해 없음 |

- 주사위는 1~6 사이의 값이 무작위로 나옵니다.
- 시작 HP는 양쪽 모두 100입니다.
- 최근 12라운드까지 하단에 전적이 기록됩니다.
